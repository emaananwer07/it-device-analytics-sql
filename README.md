# IT Device Analytics — SQL

## Overview

A beginner SQL project analysing an organisation's IT device data using PostgreSQL.

The project explores device types, manufacturers, operating systems, departments, device usage and error counts.

## Objectives

- Analyse the distribution of IT devices
- Identify device and operating system trends
- Analyse device usage and errors
- Practise relational database querying
- Use SQL to answer basic IT-related business questions

## Database Structure

The database contains three tables:

### departments
Contains information about organisational departments and their locations.

### devices
Contains information about IT devices, including device type, manufacturer, operating system, purchase year and status.

### device_usage
Contains device usage information, including monthly usage hours, error counts and the number of days since the device was last active.

## Project Questions

The project uses SQL to answer questions such as:

1. How many devices are there of each type?
2. Which operating systems are most common?
3. Which manufacturers have more than three devices?
4. Which department is each device assigned to?
5. Which devices have the highest number of errors?
6. Which devices have been inactive for more than 30 days?

## Project Purpose

This project was created to develop practical SQL and data analysis skills while applying SQL to an IT-related dataset.
